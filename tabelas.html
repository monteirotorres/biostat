Tabelas de referência

Tabelas de referência para consulta rápida. Em geral, usamos o computador (scipy.stats), mas saber ler uma tabela ajuda a entender o que o software faz — e é exigido em muitas provas.

Cada tabela traz, abaixo, a função equivalente do scipy.stats.

Tabela Z — distribuição normal padrão

Cada célula é $P(Z \le z) = \Phi(z)$, a área acumulada à esquerda de $z$. Linha = $z$ até a 1ª decimal; coluna = 2ª decimal.

Exemplo: $P(Z \le 1{,}96) = $ linha 1,9 e coluna 0,06 $= 0{,}9750$.
