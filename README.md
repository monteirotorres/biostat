## Sobre o curso

Este curso apresenta os conceitos fundamentais de bioestatística de forma intuitiva, voltado para alunos sem base sólida em matemática. Cada tópico é acompanhado de um notebook Jupyter com exemplos práticos usando Python.

## Pré-requisitos

Os exemplos práticos utilizam apenas três bibliotecas:

- `pandas` — manipulação de dados
- `seaborn` — visualização
- `scipy.stats` — funções estatísticas

Instalação:

```bash
pip install pandas seaborn scipy jupyter
```

## Estrutura

1. **Introdução** — conceitos básicos: amostra, população, variáveis, curva normal.
2. **Estatística Descritiva** — medidas de tendência central e dispersão.
3. **Probabilidade** — eventos, testes diagnósticos, distribuição binomial.
4. **Estatística Inferencial** — testes de hipóteses, intervalos de confiança, ANOVA, correlação.
